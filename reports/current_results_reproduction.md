## Full statistical re-analysis: real per-subject data, computed fresh (`paper/stats_analysis.py`)

This is the most important verification in this audit: the manuscript's statistics section
(forest plot, Table "pairedstats") turned out to have been generated from a figure script
(`paper/writeup/generate_manuscript_figures.py`) that **hardcodes the comparison numbers for
plotting** -- the actual Wilcoxon/bootstrap/rank-biserial computation that produced those numbers
was not preserved as a runnable script anywhere in the repository. This revision writes that
computation from scratch (`paper/stats_analysis.py`, subject-level paired bootstrap CI + Wilcoxon
signed-rank + matched-pairs rank-biserial + Holm-Bonferroni correction across the family) and reran
it against the real per-subject CSVs.

| Comparison | This session | Manuscript Table "pairedstats" |
|---|---|---|
| MEKT (default) -> +window | +2.01pp, 95% CI [+0.46,+3.68], p=0.0547 | +1.93pp, [+0.41,+3.59], p=0.055 |
| +window -> +corr estimator | +0.75pp, p=1.000, rank-biserial=-0.111 (4/5 improved) | +0.81pp, p=1.000, rank-biserial=-0.111 (4/5) |
| +corr -> 8-member ensemble | +1.25pp, p=0.164 | +1.18pp, p=0.129 |
| **FgMDM (baseline) -> ensemble (final)** | **+4.94pp, 95% CI [+3.38,+6.58], p=0.0039, rank-biserial=1.000 (9/0)** | **+4.94pp, [+3.38,+6.58], 0.0039, 1.000, 9/0** |

The manuscript's single most important statistical claim (FgMDM -> final ensemble) is reproduced
**exactly** by this independently-written analysis script. The three intermediate-step comparisons
match to within ~0.05-0.1pp (same small reproducibility noise as the raw accuracy numbers above,
propagated through) and reach identical qualitative conclusions (same significance decisions, same
win/loss counts, same effect-size sign). This is strong evidence the manuscript's reported
statistics are genuine and were not computed in error, even though the original computation script
itself could not be located.

After Holm-Bonferroni correction across these 5 comparisons (family-wise, this revision's
addition -- the manuscript did not previously report a multiple-comparisons correction across this
specific set): only "FgMDM (baseline) -> ensemble (final)" survives at alpha=0.05. See
`paper/results/statistical_tests_bci2a.csv` for the full output including the correction decision
per comparison -- this directly operationalizes the review's Critical Issue C request to
distinguish statistically-supported findings from empirical trends, with a correction the original
analysis did not apply.
